# AngelicaScale

AngelicaScale is an add-on for the Minecraft mod Angelica, originally designed to fulfill the author's desire to modify the rendering resolution within the GT New Horizons Minecraft modpack.

## Features

- Reduce the rendering resolution of the game visuals
- Without impacting the GUI

## Requirements

- Angelica `1.0.0-beta66b` or newer
